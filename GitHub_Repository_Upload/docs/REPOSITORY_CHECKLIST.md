# Repository release checklist

1. Create a public GitHub repository named `aml-ml-gnn-comparison`.
2. Upload the contents of this folder, not the outer ZIP itself.
3. Confirm that the notebook, README, results tables, figures, audit files, and environment record are visible.
4. Create a release using tag `v1.0.0`.
5. Attach `AML_IEEE_revision_complete_outputs.zip` to the release.
6. Open the repository in a private browser window and confirm that it is publicly accessible.
7. Run the ordered notebook once in a new Kaggle session when time permits.
8. Replace the manuscript repository placeholder only after the public URL works.
9. Add the versioned repository as an IEEE bibliography entry.
